# Parser-Fixtures

Diese Dateien enthalten anonymisierte oder synthetisch-realitätsnahe Rohtexte für Parser-Regressionstests.

- `si-bestellschein-golden.txt`: SI-Bestellschein-Rohtext für spätere Phase-2E-2A-Alt/Neu-Vergleiche der Bestellschein-Zeilenparser.

Die Fixtures dürfen keine echten Kundennamen, Adressen, Auftragsnummern oder vertraulichen Produktionsdaten enthalten.
